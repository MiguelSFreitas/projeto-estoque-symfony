# Projeto Estoque Symfony

Sistema de controle de estoque desenvolvido com Symfony, com login, cadastro de categorias e cadastro de produtos.

## Funcionalidades

- Login de usuários
- CRUD de categorias (listar, cadastrar, editar, ver e excluir)
- CRUD de produtos (listar, cadastrar, editar, ver e excluir)
- Produtos ligados a uma categoria
- Aviso de estoque baixo na listagem de produtos
- Bloqueio de exclusão de categoria que possui produtos
- Validação de formulários e proteção CSRF

## Tecnologias

- PHP
- Symfony
- Doctrine ORM e Migrations
- Twig
- MySQL
- HTML e CSS
